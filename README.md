1. Buka Unity project `Emberwake`
2. Menu **Emberwake → 2. Apply Play Store Portrait Settings**
3. Scene `Assets/Emberwake/Scenes/Millbrook_Prototype` → Play
4. Game view: aspect **Portrait**
