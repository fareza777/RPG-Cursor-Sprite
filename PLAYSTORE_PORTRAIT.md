# Emberwake — Play Store (Portrait)

## Buka & Play

1. Unity Hub → Open `C:\Pixel Game Cursor\Emberwake`
2. Menu **Emberwake → 2. Apply Play Store Portrait Settings** (sekali)
3. Buka scene `Assets/Emberwake/Scenes/Millbrook_Prototype.unity`
4. Set Game view ke **1080x1920 Portrait** (atau device Pixel 5)
5. Tekan **Play**

Bootstrap otomatis spawn: Kael, arena Millbrook, slime, Gloves pickup, HUD portrait + virtual stick.

## Kontrol

| Mobile (portrait) | Keyboard |
|---|---|
| Stick kiri bawah | WASD / Arrow |
| Stick penuh = lari | Shift |
| ATK kanan | J / Z |
| SPIN | K / X |

## Android package

- Package: `com.emberwakestudio.emberwake`
- Orientation: **Portrait only**
- Min SDK 26 · Target SDK 35 · ARM64 IL2CPP

Build: File → Build Settings → Android → Switch Platform → Build App Bundle (Play Store).

## Cerita penuh

Lihat `C:\Pixel Game Cursor\GRAND_STORY_EMBERWAKE.md` (20–30 jam).
